# مسیر استفاده از تقویم.dev

> این سند مسیر مفهومی محصول را نشان می‌دهد، نه جزئیات استقرار یا ادعای در دسترس بودن تمام مراحل. **وضعیت کنونی: دسترسی زودهنگام.**

## از آشنایی تا استفاده

```mermaid
flowchart TB
    A["آشنایی با قابلیت‌ها"] --> B["آزمایش نمونهٔ تعاملی"]
    B --> C["درخواست دسترسی زودهنگام"]
    C --> D["دعوت و فعال‌سازی پس از تأیید"]
    D --> E["ایجاد پروژه و اعتبار دسترسی"]
    E --> F["انتخاب عملیات و ارسال درخواست"]
    F --> G["پاسخ تاریخ/زمان و شناسهٔ پیگیری"]
    G --> H{"نیاز به عملیات ادامه‌دار؟"}
    H -- "خیر" --> I["استفاده از نتیجه"]
    H -- "بله" --> J["پیگیری وضعیت، رویداد و رسید"]
    J --> I
```

**توجه:** مراحل دعوت، ساخت پروژه، صدور اعتبار دسترسی و اجرای عملیات حفاظت‌شده، تنها پس از فعال‌سازی رسمی برای کاربر قابل استفاده‌اند. ابزارهای تعاملی صفحه شامل نمونه‌های نمایشی نیز هستند.

## چرخهٔ یک عملیات زمان‌دار

```mermaid
flowchart TB
    A["درخواست و هویت مجاز"] --> B["اعتبارسنجی و اعمال سیاست"]
    B --> C["محاسبه بر پایهٔ تقویم و منطقهٔ زمانی"]
    C --> D["ثبت نتیجه و شناسهٔ پیگیری"]
    D --> E{"اقدام بعدی لازم است؟"}
    E -- "خیر" --> F["پاسخ نهایی"]
    E -- "بله" --> G["زمان اجرا و وضعیت قابل پیگیری"]
    G --> H["اعلان یا رویداد"]
    H --> I["رسید، تاریخچه و بازیابی مجاز"]
```

این دیاگرام‌ها **رفتار مورد انتظار محصول** هستند و تضمین اجرای همهٔ بخش‌ها در محیط عمومی محسوب نمی‌شوند. نمونه‌های آزمایشی باید به‌وضوح از عملیات واقعی جدا شوند.
